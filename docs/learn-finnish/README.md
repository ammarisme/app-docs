# Learn Finnish — public docs

User-facing pages for the **Learn Finnish** iOS app (privacy, terms, support, remote config).

These files live under `docs/` because GitHub Pages for this repo is configured as **branch `main` → `/docs`**.

## Published files

| Path | Purpose |
|------|---------|
| [`index.html`](index.html) | Privacy policy, terms (summary), support contact |
| [`support.html`](support.html) | App Store Support URL (contact only) |
| [`api.json`](api.json) | Remote config: `apiBaseURL` (Lambda), `audioBaseURL` (R2), feature flags |
