# Mindful Lock public site

Standalone static pages owned by Mindful Lock. The repository’s `/docs` directory belongs to the existing Finnish Pro app.

- `index.html`: landing page
- `support.html`: support and troubleshooting
- `privacy.html`: privacy policy
- `terms.html`: use summary and standard EULA link
- `credits.html`: audio attribution
- `assets/`: app icon and web sizes

See the [app overview](../README.md) and [publishing package](../publishing/README.md).

Deploy only this public directory. The current GitHub Pages configuration serves `/docs` and does not publish these files automatically. The proposed public base is https://ammarisme.github.io/app-docs/mindful-lock/; configure the deployment route or update canonical URLs and submission metadata together before release.
